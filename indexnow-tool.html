常见问题

什么是 IndexNow？我为什么要用它？
IndexNow 是微软主导推出的开放协议，让网站可以**主动**通知搜索引擎「我有新内容/更新」，而不是等爬虫自己来发现。

对你的好处：
• 新内容 24 小时内就能被 Bing 抓取（以前可能要等 1-2 周）
• 通过 Bing 同步给 Yandex、Naver 等主流引擎
• 完全免费，无需 API 申请
• 一次推送，多平台收录
为什么需要上传 Key 文件到我的网站根目录？
这是 IndexNow 协议要求的所有权验证。搜索引擎会访问 https://你的域名/<key>.txt 看里面是不是确实是你声明的 key。

这能防止恶意推送：别人不能随便推一堆链接说是你的网站。

一次上传永久有效，不用每次都上传。
提交后多久能在搜索结果里看到？
• 抓取速度：通常 24-48 小时内 Bing 爬虫会到访
• 出现在搜索结果：1-7 天
• 稳定排名：1-4 周（取决于内容质量、外链）

查看是否被收录：在 Bing 搜索 site:你的域名
这个工具会推送给 Google 吗？
不会。Google 没有加入 IndexNow 协议。

要让 Google 快速收录，去 Google Search Console：
• 提交 sitemap.xml
• 用「URL 检查 → 请求编入索引」逐个推送重要页面

组合使用 GSC + 这个工具 = 覆盖几乎所有主流搜索引擎。
我可以多久推送一次？
• 每天最多 10000 个 URL（IndexNow 协议限额）
• 同一个 URL 24 小时内重复推送会被忽略
• 建议：发布新内容后立刻推送一次，无新内容时不要重复推
HTTP 200 / 202 是什么意思？失败怎么办？
200 / 202 都是成功，搜索引擎已经收到你的推送。

常见错误码：
• 400 - URL 格式有问题，检查是否完整 https://
• 403 - Key 文件验证失败，检查是否上传到根目录、内容是否就是 key 字符串本身
• 422 - 提交的 URL 不属于这个域名
• 429 - 推送太频繁，等几分钟再试

注意：浏览器的 CORS 政策会阻止前端直接调用某些端点，看到 CORS error 不代表搜索引擎没收到。建议同时勾多个端点提高成功率，或用日志中给出的 cURL 命令在终端跑。
